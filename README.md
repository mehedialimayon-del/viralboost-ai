# ViralBoost AI

Bangladesh-first social content planning and growth dashboard.

## Status

The Version 15 prototype is prepared but has **not yet been committed to this repository**. The application is not production-ready: payment gateway, AI generation, social-media OAuth and end-to-end browser testing remain pending.

## Security

Do not commit Supabase service-role keys or payment credentials. The frontend must only use a publishable/anon key with RLS.

## Planned files

- `index.html` — public landing and local prototype
- `cloud.html` — Supabase cloud workspace
- `qa_static.py` — static checks

The existing project code must be preserved when uploading.
